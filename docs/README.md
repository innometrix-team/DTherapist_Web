# DTherapist Developer Documentation

Welcome to the technical documentation for the DTherapist Web monorepo.

---

## Documentation Structure

- **`docs/architecture/`**: High-level system design, authentication flows, and real-time architecture (Agora & Socket.io).
- **`docs/api/`**: API specifications, endpoint catalogs, and TanStack Query caching strategies.
- **`docs/design-system/`**: Tailwind CSS v4 design tokens, color palette, and reusable component patterns.
- **`docs/guides/`**: Developer setup, testing, and deployment procedures.

For AI agent rules and refactoring standards, refer to [`AGENTS.md`](../AGENTS.md) and [`CLAUDE.md`](../CLAUDE.md).
